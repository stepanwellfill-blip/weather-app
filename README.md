## 🌍 О проекте

**Weather App** — адаптивное погодное приложение, которое получает актуальные данные из [OpenWeatherMap](https://openweathermap.org/) и показывает их в удобном интерфейсе.

Проект полностью работает на стороне браузера: без отдельного сервера, базы данных и тяжёлых фреймворков. В основе — обычные HTML, CSS и JavaScript.

Это учебный проект, в котором на практике используются асинхронные запросы, работа с внешним API, геолокация браузера, `localStorage`, обработка ошибок и адаптивная вёрстка.

## ✨ Возможности

### 🌦 Погода и прогноз

- **Поиск по городу** — введи название города и нажми «Найти» или Enter.
- **Геолокация** — получи погоду для своего местоположения.
- **Текущая погода** — температура, ощущаемая температура, описание и иконка погодных условий.
- **Дополнительные показатели** — влажность, скорость ветра, давление, время восхода и заката.
- **Прогноз на 5 дней** — дата, день недели, погодная иконка, описание, минимальная и максимальная температура.

### 💾 Удобство использования

- Последний выбранный город сохраняется в `localStorage`.
- При повторном посещении приложение может загрузить погоду для сохранённого города.
- Есть приветственный экран для первого запуска.
- Интерфейс показывает состояние загрузки, ошибки и успешно загруженную погоду.

### 🎨 Интерфейс

- Тёмная тема с эффектом **glassmorphism**.
- Динамический фон, который меняется в зависимости от погоды.
- Плавное появление карточек и интерактивные hover-эффекты.
- Кастомный скроллбар.
- Адаптивная раскладка для компьютеров, планшетов и смартфонов.

### 🛡 Обработка ошибок и доступность

- Город не найден — отображается понятное сообщение.
- Нет подключения к сети или API вернул ошибку — приложение сообщает о проблеме.
- Геолокация недоступна или пользователь запретил доступ — можно ввести город вручную.
- Во время загрузки показываются skeleton-плейсхолдеры.
- Для интерактивных элементов предусмотрены подписи, клавиатурная навигация и стили `focus-visible`.
- Сообщения об ошибках используют `role="alert"`.

## 🚀 Локальный запуск

### 1. Склонируй репозиторий

```bash
git clone https://github.com/stepanwillfil-blip/weather-app.git
cd weather-app
```

### 2. Добавь API-ключ

Открой `script.js`, найди объявление `API_KEY` и вставь свой ключ OpenWeatherMap:

```javascript
const API_KEY = "YOUR_OPENWEATHERMAP_API_KEY";
```

Не оставляй в публичном репозитории свой реальный ключ без необходимости. Подробнее — в разделе [безопасности API-ключа](#-важно-безопасность-api-ключа).

### 3. Запусти локальный сервер

Рекомендуемый способ — использовать расширение **Live Server** в Visual Studio Code:

1. Открой папку проекта в VS Code.
2. Установи расширение Live Server, если оно ещё не установлено.
3. Нажми правой кнопкой мыши на `index.html`.
4. Выбери **Open with Live Server**.

Обычно приложение откроется по адресу `http://127.0.0.1:5500`.

> Лучше использовать локальный сервер, а не открывать `index.html` напрямую. Геолокация браузера работает в защищённом контексте — обычно это HTTPS или localhost.

## 🔑 Настройка OpenWeatherMap API

Для получения погоды приложению нужен API-ключ OpenWeatherMap.

1. Перейди на [openweathermap.org](https://openweathermap.org/) и создай аккаунт.
2. Открой раздел **API keys** в личном кабинете.
3. Скопируй существующий ключ или создай новый.
4. Вставь его в `script.js` вместо `YOUR_OPENWEATHERMAP_API_KEY`.
5. Проверь, что для ключа доступен используемый API. Новый ключ может активироваться не мгновенно.

Приложение использует следующие методы OpenWeatherMap:

| Метод | Назначение |
| --- | --- |
| `data/2.5/weather` | Получение текущей погоды по названию города или координатам |
| `data/2.5/forecast` | Получение прогноза с интервалом в 3 часа на 5 дней |

В запросах используются метрические единицы измерения (`units=metric`) и русский язык описаний (`lang=ru`). Доступность методов и ограничения зависят от текущего тарифа OpenWeatherMap.

## ⚙️ Как работает приложение

### Основной сценарий

1. Пользователь вводит город или разрешает определить местоположение.
2. Приложение получает текущую погоду либо координаты выбранной точки.
3. По координатам запрашивается прогноз на 5 дней.
4. Данные обрабатываются и отображаются в карточках.
5. Выбранный город сохраняется в `localStorage`.

### Основные части логики

| Функция | Назначение |
| --- | --- |
| `getWeatherByCity(city)` | Получает текущую погоду по названию города и сохраняет выбор пользователя |
| `getWeatherByCoords(lat, lon)` | Получает текущую погоду по координатам |
| `getForecast(lat, lon)` | Загружает прогноз по координатам |
| `renderCurrent(data)` | Отображает текущую погоду |
| `renderForecast(data)` | Формирует и отображает карточки прогноза |
| `showError(message)` | Показывает сообщение об ошибке |
| `showLoader()` / `hideLoader()` | Управляют состоянием загрузки |
| `saveCity(city)` / `loadSavedCity()` | Сохраняют и загружают последний выбранный город |

### Состояния интерфейса

Состояние приложения задаётся через `body.dataset.state`:

| Состояние | Что отображается |
| --- | --- |
| `empty` | Приветственный экран |
| `loading` | Индикаторы загрузки и skeleton-карточки |
| `error` | Сообщение о проблеме |
| `ready` | Текущая погода и прогноз |

### Динамический фон

Цветовая схема меняется в зависимости от погодных условий. Например, для ясной погоды используются тёплые оттенки, для дождя — холодные синие и серые, для снега — голубые, а для грозы — более тёмные тона.

## 🌐 Публикация на GitHub Pages

Поскольку приложение статическое, его можно разместить на GitHub Pages.

1. Создай публичный репозиторий на GitHub.
2. Загрузи файлы проекта в корень репозитория.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери:
   - **Source:** `Deploy from a branch`;
   - **Branch:** `main`;
   - **Folder:** `/ (root)`.
5. Нажми **Save** и дождись завершения публикации.

После публикации GitHub покажет адрес сайта. Для этого репозитория ссылка имеет вид:

**https://stepanwillfil-blip.github.io/weather-app/**

## ⚠️ Важно: безопасность API-ключа

GitHub Pages публикует JavaScript-код для браузера. Поэтому ключ, записанный непосредственно в `script.js`, **будет доступен посетителям сайта** через исходный код и инструменты разработчика.

- Не загружай в публичный репозиторий ключ, который предоставляет доступ к платным или чувствительным ресурсам.
- Учитывай лимиты и условия использования своего тарифа OpenWeatherMap.
- Если нужно скрыть ключ, перенеси запросы к API на собственный сервер или серверную функцию. Простая переменная в JavaScript или файл `.env` не скрывают секреты в статическом сайте.
